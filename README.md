# shortcut-signer

Подписывает неподписанные команды iOS (.shortcut) через бесплатный macOS-раннер GitHub Actions.

## Как пользоваться

1. Положить `.shortcut`-файл в корень репозитория и запушить.
2. Actions прогонит `shortcuts sign --mode anyone` по всем `*.shortcut`.
3. Скачать артефакт `signed-shortcuts` со страницы запуска — внутри подписанные файлы.
4. Открыть подписанный файл на iPhone — импортируется в Команды.
